# 组件总览

Moluoxixi Vue组件库提供了丰富的业务组件，涵盖表单、表格、布局、工具等多个类别，助力快速构建企业级应用。

## 📊 组件分类

### 基础组件
- **Icon** - 图标组件
- **Watermark** - 水印组件  
- **Splitter** - 分割器组件

### 表单组件
- **Select** - 选择器组件
- **DateRangePicker** - 日期范围选择器
- **ConfigForm** - 配置化表单

### 表格组件
- **ConfigTable** - 配置化表格
- **DraggableTable** - 可拖拽表格
- **EnterNextTable** - 回车下一行表格
- **EnterNextDragTable** - 可拖拽回车表格
- **PopoverTableSelect** - 弹窗表格选择器

### 布局组件
- **Tabs** - 标签页组件
- **EnterNextContainer** - 回车容器组件
- **KeepAllAlive** - 全局缓存组件

### 工具组件
- **Calendar** - 日历组件
- **MarkdownEditor** - Markdown编辑器
- **ExportExcel** - Excel导出工具
- **ApiDialog** - API对话框

### 配置组件
- **ConfigProvider** - 配置提供者
- **ViteConfig** - Vite配置工具
- **EslintConfig** - ESLint配置工具

## 🚀 快速开始

每个组件都提供了详细的API文档、使用示例和最佳实践。点击左侧导航栏可以查看具体组件的使用说明。

## 📝 组件开发规范

所有组件都遵循以下开发规范：

- ✅ **TypeScript支持** - 完整的类型定义
- ✅ **响应式设计** - 适配不同屏幕尺寸
- ✅ **可访问性** - 遵循WCAG标准
- ✅ **国际化** - 支持多语言
- ✅ **主题定制** - 支持样式自定义
- ✅ **单元测试** - 保证代码质量

## 💡 使用建议

1. **按需引入** - 推荐使用按需引入方式，减小包体积
2. **TypeScript** - 建议在TypeScript项目中使用，获得更好的开发体验
3. **主题定制** - 可根据项目需求自定义主题样式
4. **版本更新** - 定期关注版本更新，获取最新功能和修复
